# 自定义业务接口

```
请为 bishe-kit 增加「{借书 / 还书}」功能：
- 新表 {borrow}(id, user_id, book_id, status, borrowed_at, returned_at)
- 用户端：POST /api/borrow 借书（库存 -1，库存为 0 时报错）、POST /api/borrow/:id/return 还书、GET /api/borrow/mine 我的借阅
- 管理端：GET /api/admin/borrow 借阅记录列表，需要权限 borrow:read（在 permissions 表登记）
- 库存变更和插入记录放在 db.transaction 里
- 风格和 server/src/routes/crud.js 保持一致，返回 { code: 0, data }
- 补充 node:test + supertest 测试
```
