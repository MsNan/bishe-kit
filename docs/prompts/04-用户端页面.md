# uni-app 用户端页面

```
请在 client/src/pages/ 下新增「{我的借阅}」页面：
- 使用 <script setup>，请求统一用 utils/request.js 的 http，不要用 axios 或 fetch
- 下拉刷新（onPullDownRefresh）和触底分页（onReachBottom）
- 需要登录：在 utils/guard.js 的 NEED_LOGIN 里登记路径
- 样式单位用 rpx，标签只用 view/text/image
- 注册到 pages.json，并从「我的」页面加入口
- 保证 npm run build:h5 和 npm run build:mp-weixin 都能编译通过
```
