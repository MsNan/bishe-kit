# 排错

```
运行 {npm run dev / npm run build:mp-weixin} 时报错，完整报错如下：
{贴完整报错，不要截图}

我的环境：Node {node -v}、npm {npm -v}、系统 {Windows / macOS}。
请先说明原因，再给出最小改动的修复方法，不要重写无关的代码。
```

常见问题：
- **端口被占用**：修改 `PORT=3001 npm run dev:server`，并同步修改 admin、client 的 `vite.config.js` 里的代理地址（或设置环境变量 `API_URL`）
- **小程序请求失败**：在 `client/.env` 里设置 `VITE_API_BASE`；开发者工具里勾选「不校验合法域名」；正式上线必须使用已备案的 https 域名
- **想重置数据**：删除 `server/data/app.db`，重新启动会自动写入演示数据
