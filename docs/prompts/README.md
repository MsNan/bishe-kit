# AI 提示词包

配合 Cursor、Claude Code、Trae 等 AI 编程工具扩展 bishe-kit。用法：把下面的提示词复制给 AI，`{}` 里换成你自己的内容。

建议先装好这两个工具，AI 写出来的代码会更规范：

- [vue-uniapp-skills](https://github.com/MsNan/vue-uniapp-skills)：Vue3 + uni-app 编码规范技能包，执行 `npx -y github:MsNan/vue-uniapp-skills`
- [cn-dev-mcp](https://github.com/MsNan/cn-dev-mcp)：节假日、校验、拼音、行政区划、uni-app/Element Plus 文档速查 MCP

| 文件 | 用途 |
| --- | --- |
| [01-项目理解.md](./01-项目理解.md) | 让 AI 先读懂项目结构，后面的改动才不会乱 |
| [02-新增业务模块.md](./02-新增业务模块.md) | 用生成器加新实体，并补充业务逻辑 |
| [03-自定义接口.md](./03-自定义接口.md) | 写 CRUD 之外的业务接口（借阅、下单、预约） |
| [04-用户端页面.md](./04-用户端页面.md) | 写 uni-app 页面，并适配 H5 和小程序 |
| [05-数据统计.md](./05-数据统计.md) | 给后台首页加图表 |
| [06-文档与答辩材料.md](./06-文档与答辩材料.md) | 根据代码整理 ER 图、接口文档、测试用例（**不代写论文**） |
| [07-排错.md](./07-排错.md) | 遇到报错时怎么问 AI |
