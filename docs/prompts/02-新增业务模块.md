# 新增业务模块

## 第一步：用生成器生成（不需要 AI）

```bash
npm run gen -- room 自习室 name:string:名称:required:search seats:int:座位数 location:string:位置 cover:image:图片 status:select:状态:options=开放|维护 --icon School --client
```

生成后重启后端，后台就会自动出现「自习室管理」菜单，用户端也会生成列表页和详情页。

## 第二步：让 AI 补充业务逻辑

```
我用 npm run gen 生成了实体 {room}（定义在 server/src/entities/{room}.json）。
请在不改动通用 CRUD 的前提下：
1. 在 server/src/routes/ 新建 {room}.js，写一个 {"用户预约座位"} 接口，挂载到 /api/{room}，要求用户端登录（requireLogin）
2. 需要新表时，在 bootstrap 里用 CREATE TABLE IF NOT EXISTS 建表
3. 参数校验失败抛 HttpError(400, '中文提示')，SQL 一律用 ? 占位符
4. 在 server/test/ 补测试：未登录返回 401、正常预约成功、重复预约失败
完成后运行 npm test，确认全部通过。
```
